# 数据约定

CellText 只提供文本预览，不声明字段关系。表格样例用 id/headers 或表头位置描述归属，脚注不属于数值；< 表示检出限，— 表示缺失，0 为数值。mg/L 与 μg/L 可按 1000 换算，其余未知单位留给业务确认。

## 结构化采集约定

- 网格：rowspan/colspan 展开占位，占位重叠即网格冲突；显式 headers 必须与位置推断一致，否则视为表头关联冲突；tbody 中重复出现的表头行替代 thead 标注后续行；单元格内的嵌套说明表不属于外层数据。
- 结构签名：由表头文本、合并方式与网格形状决定，数据单元格的取值不参与；签名变化后旧映射不再适用。
- 映射：登记时绑定结构签名与适用单位，目标单位的换算因子必须为 1；同名映射递增版本，旧版本保留。
- 事实：缺失（—）、低于检出限（<）与数值 0 分别记录；每条事实保存表、行、列与完整表头路径，可回到源表单元格。
- 存储：同一页面按同一映射版本重跑不产生重复事实；更换映射可重处理，旧版本事实不抹除；一批写入要么全部提交，要么全部回滚。
- 拒绝自动入库：未知单位、单位不在映射适用范围内、表头关联冲突、网格冲突、解析异常；此类页面进入待确认，等待运营处理。
